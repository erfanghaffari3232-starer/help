🐱 راهنمای کامل GitHub

همه چیز درباره GitHub به زبان ساده - از صفر تا صد

🚀 شروع کار با GitHub

  1. برو به سایت github.com
  2. روی Sign up کلیک کن
  3. ایمیل، پسورد و نام کاربری وارد کن
  4. ایمیلت رو تأیید کن
  5. حالا یه اکانت GitHub داری! 🎉
💡 نام کاربری رو کوتاه و ساده انتخاب کن. این اسم توی آدرس سایتت میاد!

📂 ساخت مخزن (Repository)

  1. وارد اکانتت شو
  2. بالا سمت راست، روی + کلیک کن
  3. New repository رو بزن
  4. یه اسم انتخاب کن (مثلاً my-project)
  5. Public رو انتخاب کن (رایگان)
  6. روی Create repository کلیک کن
💡 اسم مخزن رو انگلیسی و بدون فاصله بنویس. از خط تیره (-) استفاده کن.

📤 آپلود فایل

  1. وارد مخزنت شو
  2. روی Add file کلیک کن
  3. Upload files رو بزن
  4. فایل‌هات رو بکش و رها کن
  5. پایین صفحه Commit changes رو بزن
⚠️ حجم هر فایل حداکثر ۲۵ مگابایت باشه. برای فایل‌های بزرگتر از Google Drive استفاده کن.

🌐 فعال کردن GitHub Pages

  1. وارد مخزنت شو
  2. برو به Settings
  3. از سمت چپ Pages رو انتخاب کن
  4. توی Branch، main رو انتخاب کن
  5. Save رو بزن
  6. ۱-۲ دقیقه صبر کن
💡 آدرس سایتت میشه: username.github.io/repo-name/

💻 دستورات مهم Git

  • git init - شروع یه مخزن جدید
  • git add . - اضافه کردن همه فایل‌ها
  • git commit -m "پیام" - ذخیره تغییرات
  • git push - آپلود روی GitHub
  • git pull - دانلود از GitHub
  • git clone آدرس - کپی مخزن
  • git status - وضعیت فعلی
💡 این دستورات رو توی cmd یا terminal بنویس.

💡 نکات حرفه‌ای

  • ✅ اسم فایل اصلی حتماً index.html باشه
  • ✅ مخزن رو Public بذار تا Pages کار کنه
  • ✅ از فایل README.md برای توضیحات استفاده کن
  • ✅ بعد از آپلود، ۱-۲ دقیقه صبر کن
  • ✅ برای پروژه‌های شخصی License رو None بذار
  • ✅ برای پروژه‌های HTML ساده .gitignore لازم نداری
⚠️ هیچوقت رمز عبور یا اطلاعات شخصی رو توی GitHub نذار!
